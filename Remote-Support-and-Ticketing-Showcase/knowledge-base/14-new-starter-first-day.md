# New starter first-day guide

**For:** New staff

1. Sign in to your laptop with the username and temporary password your manager gives you.
2. Choose a new password (at least 12 characters).
3. Set up Microsoft Authenticator: see "Set up Microsoft Authenticator".
4. Open Outlook and Teams; they set up automatically.
5. Check your department drive is in File Explorer.
6. Bookmark this IT Help Centre.

**Anything not working?** Ask your manager to log a ticket, or contact the service desk.
