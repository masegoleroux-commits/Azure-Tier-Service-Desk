# Set up Microsoft Authenticator

**For:** All staff, including new starters

1. Install **Microsoft Authenticator** from the App Store or Google Play.
2. On a computer, go to https://aka.ms/mfasetup and sign in.
3. Choose **Add sign-in method** > **Microsoft Authenticator**.
4. In the app, tap **+** > **Work or school account** > **Scan QR code**.
5. Scan the code on screen, then approve the test notification.

**Still not working?** Check your phone's date and time are set automatically, then try again or log a ticket.
