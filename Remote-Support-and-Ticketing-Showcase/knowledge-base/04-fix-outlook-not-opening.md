# Fix Outlook not opening

**For:** All staff

1. Restart your computer.
2. Open Outlook in safe mode: press Windows key + R, type `outlook.exe /safe`, press Enter. If it opens, an add-in is the cause: File > Options > Add-ins > COM Add-ins > Go, and untick add-ins one at a time.
3. **Mailbox full message?** File > Info shows your mailbox size. Empty Deleted Items, delete large old attachments, or ask IT about an Online Archive.
4. Use Outlook on the web (https://outlook.office.com) while waiting for help.

**Still not working?** Log a ticket with the exact error message. IT can create a fresh Outlook profile for you.
