# Add a shared mailbox

**For:** Staff given access to a team mailbox

1. Access must be approved by the mailbox owner. Request it in a ticket.
2. Once access is granted, the mailbox usually appears in Outlook by itself within an hour. Restart Outlook.
3. If it doesn't appear: File > Account Settings > Account Settings > select your account > Change > More Settings > Advanced > **Add** and type the mailbox name.
4. To send as the shared mailbox, choose it in the **From** field of a new email.
