## Problem
User got a new phone; the old one was traded in. Sign-in prompts go to the old Authenticator app.

## Impact
One user blocked from email and Teams on her laptop.

## Troubleshooting
1. Verified identity by manager callback.
2. Authentication methods: only the old Authenticator registered.
3. Sign-in logs: MFA not completed, no unusual locations.

## Resolution
Removed old methods, required re-registration, and walked the user through setting up Authenticator on the new phone via aka.ms/mfasetup. Sign-in confirmed in the logs.

## Customer reply
Hi Fatima, Microsoft Authenticator is now set up on your new phone. Next time you change phones, add the new one before you hand in the old one, using "Moving MFA to a new phone" in the IT Help Centre.
