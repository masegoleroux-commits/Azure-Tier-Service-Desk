## Problem
User can't sign in to Windows. Message: "The referenced account is currently locked out and may not be logged on to."

## Impact
One user fully blocked; month-end reports due today.

## Troubleshooting
1. Verified identity by calling the manager on the directory number.
2. `05-Reset-LabUserPassword.ps1`: LockedOut = True, BadLogonCount = 5.
3. Event 4740 on DC01: caller computer CLIENT01, three lockouts since 07:30.
4. Remote session to CLIENT01: Credential Manager held an old password for `\\DC01\Finance`.

## Resolution
Removed the stale saved credential, unlocked the account and reset the password with change at next sign-in. Root cause: old password saved for the mapped drive after last week's password change.
