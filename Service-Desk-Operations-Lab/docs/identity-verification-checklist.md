# Identity Verification Checklist

Use before **any** password reset, MFA reset, account unlock or access change requested by phone, chat or walk-up.

## Accepted methods (use at least one)
- [ ] **Manager callback:** call the user's manager on the number in the directory (not a number the caller gives you)
- [ ] **Callback to the directory number:** hang up and call the user back on their listed number
- [ ] **In person** with a staff ID card

## Not accepted on their own
- Knowing their username, email address or job title (easy to find online)
- Caller ID
- A request from a personal email address
- Pressure ("I'm the CEO", "it's urgent") — urgency is a common social engineering tactic

## If verification fails
Do not make the change. Log the attempt in the ticket and notify the security contact.
